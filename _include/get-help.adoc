= 셀프 지원 옵션 사용
:allow-uri-read: 


NetApp은 다양한 방식으로 NetApp Console 로컬 배포를 지원합니다. 기술 자료(KB) 문서 및 커뮤니티 포럼 등 광범위한 무료 자체 지원 옵션을 연중무휴 24시간 이용할 수 있습니다. 지원 등록에는 웹 티켓팅을 통한 원격 기술 지원이 포함됩니다.



[[use-self-support-options]]
== 셀프 지원 옵션 사용

이러한 옵션은 연중무휴 24시간 무료로 이용할 수 있습니다.

* 설명서
+
현재 보고 계신 NetApp Console 설명서입니다.

* https://kb.netapp.com/Cloud/BlueXP["지식 기반"^]
+
NetApp 기술 자료에서 문제 해결에 도움이 되는 문서를 검색해 보세요.

* http://community.netapp.com/["커뮤니티"^]
+
NetApp Console 커뮤니티에 참여하여 진행 중인 토론을 확인하거나 새로운 토론을 시작해 보세요.
